# 📊 Power BI Sales Dashboard

## 🧠 Project Overview
This project presents an interactive **Sales Dashboard** built in **Power BI** to analyze key business metrics such as revenue trends, customer performance, and regional sales distribution.  
The goal of this project is to provide decision-makers with clear, data-driven insights that can help improve sales strategy and forecasting accuracy.

---

## 🗂️ Files in this Repository
- `Sales Dashboard.pbix` → The main Power BI dashboard file  
- `Images/` → Screenshots of the dashboard (for quick reference)  
- `README.md` → Project documentation  

---

## 🧰 Tools & Technologies Used
- **Power BI Desktop**
- **Microsoft Excel** (data source)
- **DAX (Data Analysis Expressions)** for calculated measures
- **Data Modeling** and **Visualization Techniques**

---

## 📈 Key Insights
- Identified **top-performing products** and **highest revenue-generating regions**  
- Analyzed **quaterly sales trends** to monitor performance over time  
- Evaluated **customer contribution** to total revenue  
- Provided actionable insights for **strategic sales planning**

---

## 💡 Dashboard Features
- Dynamic filtering by **region**, **product category**, and **time period**  
- KPI cards summarizing **total sales**, **profit**, and **quantity sold**  
- Trend charts and comparison visuals for **month-over-month growth**  
- Geographic heat maps showing **regional performance**
